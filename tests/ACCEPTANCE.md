# Required before release

Use copies of documents, then verify:
1. New document: type English, French accents, Arabic and Spanish; select,
   delete, undo and redo. Check keyboard input, caret and selection.
2. Apply every toolbar action and verify the document, including a 3×3 table.
3. Save a new DOCX, close and reopen in RAMD Docs AND Microsoft Word or Writer.
   Check paragraphs, styles, table layout and pagination.
4. Open an existing DOCX with images, headers, footers and tracked changes;
   edit one paragraph and save a copy. Compare all other content/layout.
5. Export PDF, open it in RAMD PDF, and compare page count and text.
6. Save to an unwritable directory: error must appear; document stays open.
7. Cancel file dialogs and close with unsaved edits: confirm no silent loss.
8. Test zoom, scrolling, find, keyboard shortcuts and a long document.
9. Keep LibreOffice open while using RAMD Docs; profiles must remain separate.
10. Inspect documents with external links or macros and verify the desired
    document-security policy before accepting untrusted files in production.

These are acceptance requirements, not claims of completed testing.
